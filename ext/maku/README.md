# MAKU inside Monomodule Euclid

This folder is a copy of the parts of **MAKU** (<https://github.com/okumurari2/maku>, the ambient machine by
okumurari, a modified version of Leo Kuroshita's **Felucca** firmware for the M-VAVE FM-1) that its browser emulator
is built from, taken at commit `392641d`, plus one file of Monomodule's own:

| What | From |
| --- | --- |
| `firmware/src/`, `firmware/hal/*.h` | MAKU, unchanged |
| `tests/hostsim.c` | MAKU, unchanged (the host build of the firmware the emulator includes) |
| `web/emu/felucca_web.c` | MAKU, unchanged (the simulated device: clock, panel, screen, flash) |
| `gen/` | generated by MAKU's own build (`./build.sh`: `tools/gen_*.py`) from its tables, fonts and CC0 samples |
| `LICENSE`, `LICENSING.md`, `LICENSES/` | MAKU's licences, unchanged |
| `plugin/maku_plugin.c` | Monomodule: the calls the plugin needs (host MIDI clock, the shared key, the parts' levels and macros, NEW WORLD, LIKE, the world and the likes as bytes) |
| `plugin/compat/sys/wait.h` | Monomodule: stand-ins that let `tests/hostsim.c` compile with MinGW (its forks are never reached) |

`plugin/maku_plugin.c` includes `web/emu/felucca_web.c`, which includes every firmware source: one translation unit,
built as a shared library with a GNU C compiler (gcc or clang; MinGW-w64 gcc on Windows) by `src/plugin/CMakeLists.txt`
and embedded in Monomodule Euclid, which loads a private copy of it for each plugin instance (`src/plugin/one/MakuHost.*`).
